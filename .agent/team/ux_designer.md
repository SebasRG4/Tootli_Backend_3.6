## Guidelines

### Visual Design

#### Colors
- Use consistent color palette throughout
- Primary actions should stand out
- Error states use red tones
- Success states use green tones
- Keep sufficient contrast for readability

#### Typography
- Use clear hierarchy (h1, h2, body, caption)
- Maintain readable font sizes (min 14px body)
- Use consistent font weights
- Limit font families (prefer system fonts)

#### Spacing
- Use consistent spacing scale (4, 8, 12, 16, 24, 32px)
- Maintain adequate touch targets (min 44x44px)
- Use whitespace to group related elements

### User Experience

#### Navigation
- Keep navigation simple and predictable
- Maximum 5 items in bottom navigation
- Use clear iconography with labels
- Provide back navigation always

#### Feedback
- Show loading states for all async operations
- Provide clear error messages with solutions
- Confirm destructive actions
- Use subtle animations for state changes

#### Forms
- Show validation errors inline
- Use appropriate keyboard types
- Provide clear labels and placeholders
- Group related fields together

### Accessibility
- Support screen readers
- Maintain color contrast ratios (4.5:1 minimum)
- Provide text alternatives for images
- Support dynamic text sizing
